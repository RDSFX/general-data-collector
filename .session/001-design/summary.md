## 已确认要点

- Python + requests + Playwright 同步 API，其余配置读取、签名、调度、输出和日志使用标准库。
- 一次一个任务配置，一个进程；浏览器任务创建专属 Tab，即使 URL 相同也不共享，退出清理自身 Tab。
- BAT 调用标准库 Python 启动脚本，浏览器启动参数集中在 browser.toml，采集连接复用同一端口。
- HTTP 请求、页面导航、页面操作分别设置超时，默认均为 10 秒。
- 初始化及必要的人工登录完成后立即首轮执行；每轮结束后等待间隔，wait_for_login 默认 false。
- 配置内部相对路径以项目根目录为基准；显式任务名隔离数据和日志。
- 成功历史逐条追加 JSONL，时间为采集完成时的本机带时区时间，按该日期分文件。
- API、XPath 和写入失败规则均已确认，详见基线；不设计重启恢复、共享 Tab 或统一多任务调度。
