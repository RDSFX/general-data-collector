## 任务定义

### T001 · 配置、执行入口和历史输出

- 范围：固定四模板映射、单配置参数的一次执行入口、公共配置校验、分类错误、JSONL 和日志；依赖声明与运行数据忽略规则。
- 接口：采用冻结的架构与配置接口；模板未实现时明确报错，不提供假成功结果。
- 验收：UTF-8 配置、非法字段/路径及多个配置参数被拒绝；用测试桩验证追加、日期分文件、写入失败退出及日志脱敏。
- 归属：建立公共配置和执行器基础，明确资源生命周期接口。

### T002 · 普通 API 与 OKX 模板

- 范围：HTTP 参数、JSON/文本请求体、解码、超时和 OKX 环境变量认证。
- 验收：本地服务覆盖 JSON/文本、最终状态非 2xx、请求异常和超时；普通 API 的 2xx 业务错误内容仍保存。固定时间的签名向量核对，验证查询串/请求体的签名内容与发送内容一致；OKX 必须同时满足 HTTP 2xx 和 code="0"，缺少 code、业务失败或非 JSON 响应不写成功记录。
- 真实验证：用户提供有效只读接口与认证环境；不执行交易或资金操作。缺失时保留未验收项。
- 共享修改：在 T001 后扩展 shared/config.py 校验与 executor.py 模板接入。

### T003 · 浏览器启动与 Tab 生命周期

- 范围：BAT 入口、标准库启动脚本、集中保存启动设置的 browser.toml、CDP 连接、专属 Tab、初始化脚本、Enter 登录确认、资源释放。启动与连接共用 debug_port，不另维护 cdp_url。
- 启动验收：修改 TOML 即可改变可执行文件、端口、用户目录及附加参数；端口与用户目录不能被 args 重复覆盖；配置 UTF-8、含空格/中文的路径、不从项目目录启动均可正确处理；配置错误和解释器缺失明确报错。
- 验收：同 URL 的两个任务产生两个 Tab；脚本在本任务导航、刷新和子 frame 生效，不做 context 级注册；Enter 前不采集；Ctrl+C 仅关闭自身 Tab，保留其他页面与浏览器；断连/Tab 关闭退出。
- 共享修改：公共配置改动在 T002 之后进行；遵守 T001 的生命周期接口。

### T004 · 浏览器 API 与页面模板

- 范围：请求 JS 协议、缺失时重新注入、请求超时、动作序列和 XPath 字段提取。
- 验收：本地页面验证登录上下文请求及 JSON/文本返回；刷新后重新注入；悬挂请求可超时；动作顺序正确、失败即停止；覆盖文本/属性、单值/多值、无匹配/缺属性规则。
- 真实验证：用户提供目标站点和 XPath/JS，登录后完成验证；缺失时记录待验收。
- 共享修改：扩展公共配置与模板接入，不修改其他任务 Tab 或 context 全局设置。

### T005 · 单任务固定间隔调度

- 范围：单配置参数、长期运行上下文、首轮执行、每轮后等待和退出清理；不加入多任务管理或重启恢复。
- 验收：可控时钟或短间隔验证成功/失败后均等待间隔，同任务不重叠；浏览器只初始化并人工确认一次；等待中 Ctrl+C 可退出；终止错误不进入无限重试。
- 归属：负责 timer.py 与 executor.py 最终生命周期集成。

### T006 · 集成验收与使用说明

- 范围：四模板、两入口、独立终端/Tab、历史输出及失败流程；更新实际命令和说明。
- 验收：逐项记录 R001-R012 证据，包含真实浏览器登录及 OKX 只读请求；日志无凭据，运行产物不纳入版本管理，依赖版本及限制有记录。
- 环境依赖：目标站点、XPath/JS、只读凭据、人工登录。缺失时完成独立验证部分，保留任务未完成状态。
- 共享修改：README、ENV、AGENTS.md 中实际命令最终由本任务维护，不擅自修改冻结范围。
